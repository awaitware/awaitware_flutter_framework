# Playground

A running demo of `awaitware_flutter_framework` — the Flutter/Dart equivalent of Tailwind's own [play.tailwindcss.com](https://play.tailwindcss.com/): one screen exercising real chains from most of the library's categories, not just an isolated snippet.

```bash
cd example
flutter pub get
flutter run
```

Try it: tap "tap me" (Transitions/Animation), hover or tap the bottom nav items (CoreConcepts' `.states(...)`), resize the window (CoreConcepts' `context.isLg`/`context.darkMode`).
